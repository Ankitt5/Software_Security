## Overview

This repository contains experiments performed in the Software Security Lab. The work focuses on understanding basic security concepts, identifying vulnerabilities, and learning secure development practices.

---

## Experiments Included

1. Vulnerability Scanning (OWASP ZAP)  
2. Browser Artifacts Analysis  
3. Code Analysis for Security Flaws  
4. Input-Based Attacks (SQL Injection & XSS)  
5. Cryptographic Hashing and Password Security  
6. Secure Code Review (Login System)  
7. Network Traffic Analysis (Wireshark)  
8. Threat Modeling using STRIDE  
9. Secure Authentication Implementation  
10. Incident Response using Log Analysis  

---

## Tools Used

- OWASP ZAP – https://www.zaproxy.org/  
- Wireshark – https://www.wireshark.org/  
- Browser Developer Tools (Chrome/Firefox)  
- Nirsoft Browser History View – https://www.nirsoft.net/utils/browsing_history_view.html  
- Python / OpenSSL  
- Spreadsheet Tools (Excel)

The main objective of this lab is to gain practical knowledge of software security by performing experiments related to vulnerability assessment, secure coding, and system analysis.
