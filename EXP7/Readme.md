# Secure Authentication with Password Hashing

## Aim
To implement a basic login system with hashed password verification.

---

## Theory
Secure authentication requires:
- Password hashing  
- Input validation  
- Secure comparison  

Hashing ensures passwords are not stored in plain text.

---

## Methodology
1. Created a simple login form  
2. Stored password as hash  
3. Used hashing algorithm (SHA-256/bcrypt)  
4. Compared user input with stored hash  
5. Verified login functionality  

---

## Results
- Password stored securely as hash  
- Login worked with correct credentials  
- Plain text password not stored  

---

## Discussion
Secure authentication is important for protecting user accounts. Hashing improves security significantly.

---

## Future Scope
- Add multi-factor authentication  
- Use advanced hashing (bcrypt)  
- Implement full authentication system
