# Secure Code Review of Login System

## Aim
To review a login system and identify insecure coding practices.

---

## Theory
Login systems must be secure to protect user data. Common issues include:
- Plain-text password storage  
- No input validation  
- Weak authentication logic  

---

## Methodology
1. Collected a sample login code  
2. Reviewed input handling  
3. Checked password storage method  
4. Identified missing validations  
5. Suggested improvements  

---

## Results
- Password stored in plain text  
- No validation on user input  
- No hashing mechanism  

---

## Discussion
The login system was vulnerable due to poor coding practices. Secure coding is necessary to protect user accounts.

---

## Future Scope
- Implement secure login system  
- Add hashing and validation  
- Use authentication frameworks  

---

## Tools Used
- Manual Code Review
