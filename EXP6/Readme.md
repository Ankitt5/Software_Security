# Threat Modeling using STRIDE

## Aim
To identify possible threats in a web application using STRIDE methodology.

---

## Theory
STRIDE is a threat modeling technique:
- S: Spoofing  
- T: Tampering  
- R: Repudiation  
- I: Information Disclosure  
- D: Denial of Service  
- E: Elevation of Privilege  

---

## Methodology
1. Selected a sample web app (e.g., online bookstore)  
2. Identified system components  
3. Listed possible threats using STRIDE  
4. Analyzed attack surfaces  
5. Suggested mitigation strategies  

---

## Results
- Identified multiple threats in each STRIDE category  
- Found weak authentication points  
- Noted possible data exposure risks  

---

## Discussion
Threat modeling helps in understanding risks before development. It improves overall system security.
